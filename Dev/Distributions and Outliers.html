EDA Objective

Start EDA with the distribution of the target variable, y, and then move on to the distribution of the predictors. Inspect dataset for missing values and outliers. Preview correlation between the predictors and the target variable.

Ingest

EDA is on the bank-additional-full.csv dataset, which contains all examples, ordered by date (from May 2008 to November 2010). The dataset has 41,188 rows and 21 columns. The target variable is y, which indicates whether the client subscribed to a term deposit. The predictors include both numerical and categorical variables, such as age, job, marital status, education, default, balance, housing loan, personal loan, contact communication type, day of the week, month of contact, duration of the call, number of contacts performed during this campaign and for this client (numeric), number of days since the client was last contacted from a previous campaign (numeric), number of contacts performed before this campaign and for this client (numeric), outcome of the previous marketing campaign (categorical), employment variation rate (numeric), consumer price index (numeric), consumer confidence index (numeric), euribor 3 month rate (numeric), and number of employees (numeric).

Distribution of Response

The distribution of the response variable y is shown below. The majority of the observations are “no” (not subscribed), with a smaller proportion of “yes” (subscribed). This indicates that the dataset is imbalanced, which may affect the performance of predictive models.

Distributions of Numerical Predictors

# Identify numerical predictors
num_vars <- bank_add %>%
  select(where(is.numeric)) %>%
  names()

# Convert to long format for faceting
bank_long <- bank_add %>%
  select(all_of(num_vars)) %>%
  pivot_longer(
    cols = everything(),
    names_to = "Predictor",
    values_to = "Value"
  )

# Plot distributions
ggplot(bank_long, aes(x = Value)) +
  geom_histogram(
    bins = 30,
    fill = "steelblue",
    color = "white"
  ) +
  facet_wrap(~ Predictor, scales = "free", ncol = 3) +
  labs(
    title = "Distributions of Numerical Predictors",
    x = "Value",
    y = "Frequency"
  ) +
  theme_minimal() +
  theme(
    strip.text = element_text(face = "bold"),
    plot.title = element_text(face = "bold")
  )

Faceted Bar Charts for Categorical Predictors

Faceted bar charts for categorical predictors: notice that many predictors have ‘unknown’ as a category, which may need to be addressed in the cleaning process.

# Identify categorical predictors

Missing or Unknown Values

There are no missing values in the dataset. However, default, education, housing, loan, job, and marital have “unknown” values. The table below shows the proportion of unknown values for each predictor. This will help identify which predictors may need to be cleaned or imputed.

# look for missing values in the dataset
sum(is.na(bank_add))
[1] 0
# look for unknown values in the dataset
sum(bank_add == "unknown") / sum(bank_add != "unknown")
[1] 0.0149232
# breakdown the proportion of unknown values by predictor
unknown_summary <- bank_add %>%
  summarise(across(everything(), ~ sum(. == "unknown") / n())) %>%
  pivot_longer(
    cols = everything(),
    names_to = "Predictor",
    values_to = "Proportion_Unknown"
  ) %>%
  arrange(desc(Proportion_Unknown))

# Display results
