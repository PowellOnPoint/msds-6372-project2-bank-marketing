Relationships between Predictors and Target Variable and Among Predictors

The following analysis explores the relationships between the predictors and the target variable, as well as the relationships among the predictors themselves. This will help identify potential multicollinearity issues and inform feature selection for predictive modeling.

Compare Loess and Logistic Regression Fits

The loess curve helps us discover potential non-linear relationships between the numerical predictors and the target variable. The logistic regression curve provides a parametric fit that can be used for prediction. By comparing these two curves, we can assess whether a linear model is appropriate or if a more flexible model may be needed.

for (var in num_vars) {

              aes(x = .data[[var]], y = y_num)) +

Polished VIF View

Note on df adjustment: For a categorical variable with k levels, the degrees of freedom (df) is k-1. The GVIF is adjusted by taking the (1/(2*df)) root to make it comparable across variables with different df. The VIF equivalent is then calculated as the square of the adjusted GVIF. This allows for a more interpretable measure of multicollinearity that accounts for the number of levels in categorical predictors.

library(tibble)

vif_results <- vif(full_model_no_loan)

if (is.matrix(vif_results)) {

  vif_table <- as.data.frame(vif_results) %>%
    rownames_to_column("Predictor") %>%
    transmute(
      Predictor,
      GVIF = GVIF,
      Df = Df,
      Adjusted_GVIF = GVIF^(1 / (2 * Df)),
      VIF_Equivalent = Adjusted_GVIF^2
    )

} else {

  vif_table <- tibble(
    Predictor = names(vif_results),
    GVIF = as.numeric(vif_results),
    Df = 1,
    Adjusted_GVIF = sqrt(GVIF),
    VIF_Equivalent = GVIF
  )

}

library(gt)

vif_table <- vif_table %>%
  mutate(
    Concern = case_when(
      VIF_Equivalent < 5 ~ "Low",
      VIF_Equivalent < 10 ~ "Moderate",
      TRUE ~ "High"
    )
  ) %>%
  arrange(desc(VIF_Equivalent))

vif_table %>%
  gt() %>%
  tab_header(
    title = "Multicollinearity Diagnostics",
    subtitle = "Full Logistic Regression Model"
  ) %>%
